**Goal:** Finish the two remaining RAM-reduction items from `HANDOFF.md`, then rename the shipped
product from "Tinycast" to "Mote" across the app, its build tooling, and its core docs — without
touching the stale `website/` docs site, GitHub templates/CI, or legal documents, and without
rewriting any reference to real external infrastructure (GitHub repo, Homebrew tap/cask, Pages URL).

list — a source-folder move, an XcodeGen regenerate, and mechanical string replacement — verified
by the existing 18-harness test suite and a full Debug build.

**Tech Stack:** Swift 6, SwiftUI + AppKit, XcodeGen, the project's own `Scripts/run-tests.sh` /
`Scripts/lint.sh` / `Makefile`. No new dependencies.

**Spec:** None separate — this plan captures the full requirement inline (see Global Constraints).
User confirmed the rename scope via an explicit choice: "App + build tooling + core docs only" —
i.e. NOT `website/content/**`, NOT `.github/**`, NOT `CONTRIBUTING.md` /
`CONTRIBUTOR_LICENSE_AND_FEEDBACK_AGREEMENT.md` / `SECURITY.md` / `NOTICE.md`, and NOT `HANDOFF.md`
(a historical record of a prior session — leave it accurate to what it described at the time).

### Task 1: Lazy-load `LauncherRankingStore`'s on-disk table

**Files:**
- Modify: `Tinycast/Features/Launcher/Model/LauncherRankingStore.swift`
- Test: `Tests/ranking-test.swift` (existing, unmodified — it is the regression check)

**Interfaces:**
- Consumes: nothing new.
- Produces: no signature changes. `records`, `isEmpty`, `record(itemKey:query:)`,
  `boosts(query:)`, `hasRanking(for:)`, `reset(itemKey:)`, `resetAll()`, `flush()` keep their exact
  existing names, parameter types, and return types — `Tinycast/App/AppCore.swift`,
  `Tinycast/Features/Launcher/Service/AppIndex.swift`,
  `Tinycast/Features/Launcher/UI/AppActionsMenu.swift`,
  `Tinycast/Features/Launcher/UI/LauncherCoordinator.swift`, and
  `Tinycast/Features/Settings/Panes/GeneralSettingsView.swift` all call these and must not need
  changes.

**Why:** `init(fileURL:now:)` currently does a synchronous `Data(contentsOf:)` +
`JSONDecoder().decode(...)` read every time `AppCore`'s `private init()` runs — i.e. on every app
launch, before the palette is ever opened. `HANDOFF.md` names this as one of the three
not-yet-implemented RAM/launch trims. The fix: keep `init` free of disk I/O; do the read once, on
the first call that actually needs `records`.

Run: `sed -n '1,45p' Tinycast/Features/Launcher/Model/LauncherRankingStore.swift`
Expected: matches the version below (constructor at lines 31–44, `records` declared at line 22).

- [ ] **Step 2: Replace the eager-load constructor with a lazy-load gate**

Replace:
```swift
    private(set) var records: [LauncherRankingRecord]
    /// Part of `AppIndex`'s cache key, invalidating a result after a visit or a reset.
    private(set) var revision = 0

    /// `boosts(query:)` builds this from a launcher render; tracked, the write lands mid-body.
    @ObservationIgnored private var lookup: [String: [String: LauncherRankingRecord]]?
    /// The in-flight persist, awaited by the next one so a burst can't land out of order.
    @ObservationIgnored private var writeTask: Task<Void, Never>?

    init(fileURL: URL? = nil, now: @escaping () -> Date = Date.init) {
        self.fileURL = fileURL ?? Self.defaultFileURL()
        self.now = now

        if let data = try? Data(contentsOf: self.fileURL),
            let decoded = try? JSONDecoder().decode([LauncherRankingRecord].self, from: data)
        {
            records = decoded.filter {
                !$0.itemKey.isEmpty && !$0.query.isEmpty && $0.count > 0
            }
        } else {
            records = []
        }
    }

    var isEmpty: Bool { records.isEmpty }
```
with:
```swift
    private(set) var records: [LauncherRankingRecord] = []
    /// Part of `AppIndex`'s cache key, invalidating a result after a visit or a reset.
    private(set) var revision = 0

    /// `boosts(query:)` builds this from a launcher render; tracked, the write lands mid-body.
    @ObservationIgnored private var lookup: [String: [String: LauncherRankingRecord]]?
    /// The in-flight persist, awaited by the next one so a burst can't land out of order.
    @ObservationIgnored private var writeTask: Task<Void, Never>?
    /// Gates the on-disk read to first real use, so launch never pays for it.
    @ObservationIgnored private var hasLoaded = false

    init(fileURL: URL? = nil, now: @escaping () -> Date = Date.init) {
        self.fileURL = fileURL ?? Self.defaultFileURL()
        self.now = now
    }

    /// The on-disk table, read once on first access rather than at launch.
    private func ensureLoaded() {
        guard !hasLoaded else { return }
        hasLoaded = true
        guard let data = try? Data(contentsOf: fileURL),
            let decoded = try? JSONDecoder().decode([LauncherRankingRecord].self, from: data)
        else { return }
        records = decoded.filter {
            !$0.itemKey.isEmpty && !$0.query.isEmpty && $0.count > 0
        }
    }

    var isEmpty: Bool {
        ensureLoaded()
        return records.isEmpty
    }
```

- [ ] **Step 3: Add the `ensureLoaded()` gate to every other entry point that reads or mutates `records`**

In `record(itemKey:query:)`, add `ensureLoaded()` as the first line of the function body (before
the `let query = Self.normalize(query)` line).

In `boosts(query: String) -> [String: Int]`, add `ensureLoaded()` as the first line (before
`let query = Self.normalize(query)`).

In `hasRanking(for itemKey: String) -> Bool`, add `ensureLoaded()` as the first line, and prefix
the existing `records.contains { ... }` line with `return` — its function body was a single
expression relying on Swift's implicit return, which stops applying once a second statement
(`ensureLoaded()`) is added, so leaving out `return` is a compile error (`missing return in
instance method expected to return 'Bool'`). The corrected body:
```swift
    func hasRanking(for itemKey: String) -> Bool {
        ensureLoaded()
        return records.contains { $0.itemKey == itemKey }
    }
```

In `reset(itemKey: String)`, add `ensureLoaded()` as the first line (before
`let oldCount = records.count`).

In `resetAll()`, add `ensureLoaded()` as the first line (before `guard !records.isEmpty else`) —
this one matters: without it, calling `resetAll()` before any other access would see the
still-empty in-memory `records`, skip the persist, and leave stale on-disk data behind.

`flush()` needs no change — it only awaits `writeTask`, which is only ever set inside
`didMutate()`, which is only ever reached after one of the methods above has already called
`ensureLoaded()`.
